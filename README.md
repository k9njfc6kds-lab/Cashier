
# Cashier

A simple, dark-themed sales management and receipt application.

Built with:
- HTML
- CSS
- Vanilla JavaScript

## Features

- Dashboard with sales statistics
- Create customer receipts
- Customer username and phone
- Product and brand descriptions
- Customer location
- Automatic date and time
- Payment methods
- Weekly sales dashboard
- Sales history and search
- Edit and delete receipts
- Print receipts
- CSV export
- JSON backup and import
- Custom business name and currency
- Mobile-friendly interface
- Basic offline support

## Installation

1. Create a GitHub repository named `Cashier`.
2. Upload all seven project files to the root directory.
3. Open repository Settings.
4. Select Pages.
5. Under Build and deployment, choose Deploy from a branch.
6. Select the `main` branch and `/ (root)`.
7. Save.
8. Wait for GitHub Pages to publish the application.

## Data storage

This version uses browser localStorage.

Receipts are stored in the browser where they were created.

Data is not automatically synchronized between devices.

Use the JSON backup feature to export and restore records.

## Important

This is a frontend-only application.

It does not include server-side authentication, cloud synchronization,
or multi-user access control.

For business-critical use, add a secure backend and regular backups.
